# Student Task Management Application

A simple web application to add, display, complete and search student tasks.

## Team Members
- Student 1: Faiz-ul-Maram (GitHub: FaizulMaram)
- Student 2: ProfessionalSolutiones (GitHub: ProfessionalSolutiones)

## Features
- Add a task with a title and description
- Display tasks as styled task cards
- Mark tasks as completed (click a card)
- Search tasks by title or description in real time
- Responsive layout for mobile screens

## Technologies
- HTML5
- CSS3
- JavaScript (vanilla)
- Git & GitHub

## Git Workflow
Feature-branch workflow: each feature was developed on its own branch, pushed to GitHub, reviewed by the other student through a Pull Request, and merged into main. Issues were used to plan work and were closed automatically by linked Pull Requests.

## Branches
- main - stable branch
- feature/task-form - task input form (Student 1)
- feature/task-style - styling and task cards (Student 2)
- feature/task-search - task search feature (Student 2)
- conflict/student1 and readme-student2 - used to create and resolve a deliberate README merge conflict

## Git Commands Demonstrated
init, status, add, commit, log, branch, switch, diff, clone, remote, push, fetch, pull, merge, stash, restore, reset, revert, show, blame, tag

## GitHub Features Demonstrated
Repository hosting, Issues, Pull Requests, code review (comments and approvals), merges, linked issues (Closes #n), tags and Releases, contributors insights

## How to Run
1. Clone the repository: `git clone https://github.com/FaizulMaram/student-task-manager.git`
2. Open `index.html` in any modern browser
3. Add tasks with the form, click a card to complete it, and use the search box to filter tasks
